# Productivity Dashboard

A browser-based dashboard I built to replace the default new tab page. Combines three tools I actually use — a live clock, a calculator, and a sticky notes section — into one clean layout.

---

## What's inside

- **Clock** — live digital clock with date display
- **Calculator** — basic arithmetic, keyboard-friendly
- **Notes** — type and save short notes in the browser

---

## Running it

```bash
git clone https://github.com/kunalshahdev/Productivity-Dashboard.git
```

Then just open `index.html` in your browser. No installs, no build step.

---

## Stack

Vanilla HTML, CSS, JavaScript. No frameworks, no dependencies.

---

## Why I built it

I wanted a focused tab that shows me the time, lets me do quick math, and has somewhere to dump a thought without opening a whole app. Turns out building it yourself is faster than trying six different extensions.
